## Классы и объекты

## Цель работы
Создание консольного приложения «Сеть библиотек» для управления филиалами
и изданиями с использованием ключевых принципов ООП, безопасного ввода
данных и контроля версий через Git.

## Структура проекта
`Book.h` / `Book.cpp` — класс сущности «Издание»
`Branch.h` / `Branch.cpp` — класс сущности «Филиал» (вместимость,
каталог изданий как коллекция объектов `Book`).
`main.cpp` — меню пользователя, обработчики команд и функции валидации
ввода (`readInt`, `readLine`).

## Основной функционал
Ручное добавление данных: добавление новых изданий через
текстовое меню.
Просмотр списков: вывод текущей информации о филиалах и книгах в них.
Удаление изданий.

## Ограничение предметной области
Филиал не может принять книгу (при добавлении, возврате или
перемещении), если число хранящихся в нём изданий уже равно его
вместимости — программа проверяет это при каждой такой операции.
